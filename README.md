# Grok

A landing page that introduces Grok, the model built by xAI.

## Setup

1. `git clone` this repo
2. `npm install`
3. Copy `.env.example` to `.env` if you add variables later. None are required.
4. `npm run dev` opens at [localhost:5173](http://localhost:5173)

## Deploy

Deployed on Vercel from `main`.
